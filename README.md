# Panha Tool Updates

Public, binary-only update channel for Panha desktop applications.

- Source code remains in private repositories.
- No API keys, account databases, cookies, sessions, or user settings belong here.
- Each application reads its own JSON manifest from `channels/`.
- Installers are published as GitHub Release assets and must match the SHA-256
  value in the manifest before installation.

Applications: Cambo Dubber, Theara, DramBox Downloader, Reg Account,
Tool Reg KH, Telegram Adder, Prompt to VDO, Telegram Chat Downloader, and
Sambo Local AI Studio.
